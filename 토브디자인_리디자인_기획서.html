Critical Issues

C1
블루 컬러 조합 촌스러움
#7aa7e3 헤더 + #1d55a0 네비 + 흰 배경의 조합이 2010년대 기업 사이트 느낌. 웜 뉴트럴 보조색 부재
C2
과도한 세로 길이 + 여백
메인 페이지가 히어로 + 간단 텍스트뿐인데 2-3스크롤. 정보 밀도 극히 낮음
C3
포트폴리오 이미지 녹색 워터마크
시공사례 이미지 하단에 연두색 "ToV 인테리어" 배너가 작품 품질을 저해

Improvement Areas

I1
히어로 타이포그래피 비례
"토브하우스" 한글이 과도하게 크고 볼드. 영문 "TOV INTERIOR"와 크기 밸런스 부재
I2
"인테리어 자재 원가 공개" 배너
파란 배경 + 큰 따옴표 + 아이콘 조합이 신뢰감보다 촌스러운 인상
I3
네비게이션 + 푸터 구조
상단 파란 바 + 국기 아이콘 불필요. 푸터 "시공문의상담" 배너가 과도하게 큼

페이지별 설계

01 메인 페이지 (One-Page Compressed)

섹션 구성 (위→아래)

  1. Sticky Navigation — 로고 + 4개 메뉴 + 견적 CTA 버튼
  2. Hero Bento — 좌: 풀블리드 시공사례 이미지 / 우: 슬로건 + CTA
  3. Value Props — 3+1 벤토 (시공실적, 투명견적, 맞춤디자인 + 최근사례 슬라이더)
  4. Portfolio Preview — 필터 탭(주거/상업) + 5개 썸네일 + "더보기"
  5. Process + CTA — 좌: 4단계 시공 프로세스 / 우: 간편 견적 폼
  6. Footer — 2컬럼 (연락처+주소 / 영업시간+소셜)

핵심 변화

  • 기존 메인은 히어로+텍스트 2개 섹션 → 6개 밀도 높은 섹션으로 압축
  • 세로 길이: 약 3000px → 약 1800px 목표
  • 견적 CTA가 히어로, 프로세스 섹션, 모바일 플로팅 등 3곳에 배치
  • 모든 섹션 사이 구분선 대신 배경색 교차로 자연스러운 분리
  • 포트폴리오 프리뷰로 리모델링사례 페이지 진입 유도
02 토브하우스 소개 페이지

현재 → 개선

  • 로고 이미지 + 장문 소개 텍스트 → 히어로 이미지 + 간결한 브랜드 스토리
  • Q&A 형식 장점 설명 → 아이콘 + 숫자 기반 비주얼 카드
  • 대표 정보 없음 → 대표 인사말 + 팀 소개 (선택)

섹션 구성

  1. 브랜드 히어로 (시공 현장 이미지 + 미션 스테이트먼트)
  2. 핵심 가치 3가지 (투명, 맞춤, 소통) — 아이콘 카드
  3. 시공 프로세스 타임라인 (4단계 비주얼)
  4. 실적 수치 (시공 건수, 만족도, 경력 등)
03 리모델링사례 (포트폴리오)

현재 → 개선

  • 4열 단순 그리드 → Masonry/Bento 그리드 + 호버 상세
  • 녹색 워터마크 → 미니멀 로고 오버레이 (우하단, 반투명)
  • 주거/상업 2탭 → 지역, 평수, 공간 타입 필터 추가
  • 텍스트만 있는 제목 → 지역 + 평수 + 타입 태그 시스템

포트폴리오 카드 구성

  • 이미지 (aspect-ratio: 4/3)
  • 호버 시: 다크 오버레이 + 프로젝트명 + "자세히 보기"
  • 하단: 지역 태그 + 평수 + 공간 타입 배지
  • 클릭 시: 라이트박스 갤러리 (Before/After 슬라이더)
04 견적신청 페이지

현재 → 개선

  • 단순 폼 나열 → 2컬럼 레이아웃 (좌: 폼 / 우: 신뢰 요소)
  • 텍스트 입력만 → 드롭다운, 라디오, 레인지 슬라이더 혼합
  • 개인정보 안내만 → 예상 소요 시간 + 응답률 표시

폼 필드 재설계

  1. 이름 (텍스트)
  2. 연락처 (통합 입력, 자동 하이픈)
  3. 지역 (드롭다운: 시/군/구)
  4. 공간 종류 (라디오: 주거/상업/기타)
  5. 평수 (레인지 슬라이더 + 직접입력)
  6. 예산 범위 (드롭다운: 구간별)
  7. 희망 일정 (날짜 피커)
  8. 상세 문의 (텍스트에어리어)
  9. 참고 자료 (드래그앤드롭 파일 업로드)
05 공지사항/커뮤니티
의사결정 필요: 현재 빈 페이지. 아래 2가지 방향 중 선택 필요

Option A: 유지 (공지사항)

  • 시공 진행 공지, 휴무 안내 등 최소한의 게시판
  • 콘텐츠 관리 부담 최소화
  • 빈 상태 방지를 위한 초기 게시물 3-5개 필요

Option B: 전환 (인테리어 팁/매거진)

  • SEO 유입 + 전문성 어필 (인테리어 트렌드, 자재 가이드)
  • 콘텐츠 생산 부담 있음 (월 2-4건)
  • 장기적 가치 높음

  • ⚠ 기존 이미지에 녹색 "ToV 인테리어" 워터마크가 포함됨 → 원본 확보 필수
  • ⚠ 임웹(imweb) 호스팅 이미지 URL은 마이그레이션 후 접근 불가 → 사전 다운로드
  • ⚠ 이미지 포맷: 원본 → WebP/AVIF 변환 필요 (품질 85-90%)
