입력 필드 상세

1. 프로젝트 제목 + 카테고리

제목은 관리 용도로 사용됩니다.

예: 서울 성북구 석관동 아파트 49평

카테고리: 주거공간 / 상업공간 / 종합건축 / 맞춤가구

2. 시공정보 (사이드바)

이 정보가 홈페이지 상세페이지 좌측 Project Info 사이드바에 표시됩니다.

필드 예시 사이드바 표시
지역 서울 성북구 석관동 지역
공간유형 아파트 공간 유형
면적 49평 면적 (하이라이트)
시공기간 약 8주 시공 기간
시공비용 1억 7000 시공 비용 (하이라이트, 큰 글씨) + "만원" 자동 추가

3. 공간별 이미지 블록

작업 방법
블록 추가 "공간 블록 추가" 버튼
블록명 예: 시공 전 주방, 시공 후 거실, 욕실
이미지 추가 블록 내 + 버튼 (다중 선택 가능)
삭제 이미지 X / 블록 X
홈페이지 자동 레이아웃: 1~2장 넓게, 3장 가로, 4장 2x2 그리드. 세로 사진은 크롭 후 클릭 시 원본. 블록당 최대 15장, WebP 자동 변환.

4. 실행내역서 (OCR)

  1. 내역서 이미지(JPG/PNG) 업로드
  2. Google Vision OCR로 항목/금액 자동 추출
  3. 인식 결과를 수정 가능 (항목 추가/삭제도 가능)
  4. 홈페이지에서 테이블 + "원본 확인하기"로 표시
OCR 인식률 높이기: 선명한 이미지, 정면 촬영, 표 형태. 손글씨는 인식률 낮음.

5. 계약자 정보

관리자 전용 외부 비공개

계약자명과 연락처를 입력합니다. 접수 데이터의 연락처와 매칭되면 접수관리의 계약후기 통계에 자동 반영됩니다.

홈페이지에 절대 노출되지 않습니다.

수정 및 삭제

작업 방법
수정 카드 클릭 → 편집 모달 → 저장
삭제 모달 좌측 하단 삭제 버튼
순서 변경 카드 드래그 또는 순번 배지 클릭
공개/비공개 모달 내 토글 스위치

등록 전 체크리스트

  • 프로젝트 제목 입력
  • 카테고리 선택
  • 시공정보 입력 (지역, 공간유형, 면적, 시공기간, 시공비용)
  • 대표 썸네일 (가로형 권장)
  • 공간 블록 1개 이상 + 이미지 1장 이상
  • 계약자명 / 계약자 연락처
  • 공개 설정 확인
  • 저장 후 홈페이지에서 확인
