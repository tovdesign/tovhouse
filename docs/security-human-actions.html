🔴 2. Apps Script 스크립트 속성 등록

24h 안에

.gs 코드는 이미 PropertiesService로 전환됐지만, Script Properties에 값을 등록하지 않으면 함수 호출 시 Missing script property로 실패. 법인+개인 각각 등록 필요.

① 법인 웹앱:
  1. Apps Script 프로젝트 열기 (법인 — tov-corporate-webapp)
  2. 좌측 톱니 아이콘(프로젝트 설정) 클릭
  3. 하단 "스크립트 속성" → "스크립트 속성 추가" 3번
  4. 3개 속성 등록 (값은 BotFather에서 회전한 새 값 사용):
    • WEBHOOK_SECRET = 새로 생성한 32자+ 랜덤 문자열 (기존 kpolicy2025secret 대체)
    • TELEGRAM_BOT_TOKEN = 회전한 새 봇 토큰
    • TELEGRAM_CHAT_ID = -1003061443160
  5. 저장 → 배포 → 새 버전 배포 (기존 URL 유지)
  6. Make.com 시나리오에서 해당 웹앱 호출 시 query string의 secret= 값을 새 WEBHOOK_SECRET과 일치하도록 업데이트
② 개인 웹앱:

동일 절차. 단 WEBHOOK_SECRET은 법인과 같거나 달라도 무방 (Make 시나리오별로 맞추면 됨). 

# 안전한 WEBHOOK_SECRET 생성 (PowerShell)
[Convert]::ToBase64String((1..32 | ForEach-Object { Get-Random -Maximum 256 }))

# 또는 Node.js
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
