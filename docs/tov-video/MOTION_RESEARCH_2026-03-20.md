## Part 2: 추출된 모션 기법 패턴 분류 (Remotion 구현 가능)

### A. 데이터 시각화 (12개 사례에서 반복)

| 기법                     | 설명                               | 사용 기업                    | Remotion 구현                      |
| ------------------------ | ---------------------------------- | ---------------------------- | ---------------------------------- |
| **Bar Chart Animation**  | 막대가 spring으로 성장             | Accelerant, IXL              | `spring()` + stagger delay         |
| **Pie Chart Stroke**     | strokeDashoffset으로 세그먼트 등장 | CEDAR, Arcadia               | SVG circle + `interpolate()`       |
| **Line Chart Path Draw** | SVG path가 그려지는 효과           | Agrio, Chargebee             | `@remotion/paths` + `evolvePath()` |
| **Number Counter**       | 숫자가 올라가는 카운팅             | SourceBreaker, CEDAR, Remote | `CountUp` 프리미티브 (이미 구현)   |
| **Progress Bar Fill**    | 프로그레스바가 차오르는 효과       | PagerDuty, BetterCloud       | `interpolate()` width              |
| **World Map Hotspots**   | 지도 위 핫스팟 순차 등장           | Remote, PayPal, Deel         | `Stagger` + `PopBadge`             |
