DOCUMENT 02

시공 사례 등록 절차, 이미지 블록 구성,

등록 흐름

기본정보 → 시공정보 → 이미지 블록 → 내역서 → 계약자 → 저장

주요 내용

프로젝트 제목 + 카테고리 + 시공정보 입력
공간별 이미지 블록 구성 (시공 전/후)

계약자 정보 (외부 비공개)
공개/비공개 설정 + 순서 변경
